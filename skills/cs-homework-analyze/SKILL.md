# 已有结果分析

显式只读、禁止执行或仅报告建议统一遵守 [当前范围的只读边界](../cs-homework/references/continuity.md)：先整理当前范围，仅阅读和在聊天中反馈；旧授权不允许分析、编译或任何作业、状态与 Git 写入。

先读共享的 [当前范围、工具与跨聊天交接](../cs-homework/references/continuity.md)，读取作业内的诊断与待决定事项；内部分析保持本次整体请求与范围，必要工具从当前安装提示定位并重新验证。

接手本次请求、作业材料、已有数据及原作业目录，先确认用户要回答的问题和交付物。在分析范围内连续完成，不要求先规划、实现代码或重跑实验，也不自动写完整报告。当前请求决定范围，旧状态中的计划和下一步不构成新授权。

按共享交接约定读取普通记录与实际数据，结构化状态及 `resume` 是可选辅助；分析前读 [结果有效性与来源](../cs-homework/references/results.md)。真实有效的结果、分析、表和图可以直接复用，缺内部 ID 不构成重算理由。

直接收到 CSV、日志、截图或其他外部数据时，实际读取内容，记录谁提供、位置及已知生成条件；按实际路径直接使用原始文件，保存来源说明与精确输入版本，不补造命令、测量或源码版本；无需先 `import-result` 或取得结果 ID。外部结果的“有效”只指文件当前且完好，不代表生成过程或正确性已独立核验。旧工作流尚未登记的真实运行也可直接读取实际日志和输出，保留已有执行来源；不能把旧工作流真实运行误写成用户外部测量。旧登记接口仅在有明确用途时选用。

围绕当前分析目标核对列名、行数、数据类型、缺失、重复、非有限值、单位、测量条件和可疑值。保留原始数据；不能静默删异常、补零、插值、改单位或把未运行情况当作零耗时。能从资料直接确定的事实自行确认；单位、样本含义或处理规则会影响结论且仍不明确时，问具体问题并给推荐处理与依据，继续不依赖答案的部分。数据不全可准确交付受限分析，不强凑统计检验、误差条或额外性能实验。

选择回应任务的指标和图表。由你理解含义并编写计算，不使用关键词分类器代替阅读。计算、表、图和正文使用同一份精确结果字节；保留输入版本、公式、转换、单位与产物对应。先核对少量独立已知值或手算结果，尤其是单位换算、分组、比例与分母。作图使用适用且实际可用的标准工具，如 Matplotlib；不必为简单表格安装绘图库。图轴和表头写清单位，标注比较条件，只有相应数据存在时才画误差线。

需要新计算时，读 [分析执行与交接](../cs-homework/references/analysis.md)。在实际作业目录直接编写或小范围修改分析脚本；按 [编辑保护与真实执行](../cs-homework/references/coding.md) 在首次编辑前保护既有内容，并用普通工具或可选 `capture-run`（`role: analyze`）保存真实执行事实。只读取选定数据、完成当前派生计算并写入本次产物；不借计算运行学生程序、扩大实验或修改课程实现。原始数据保持不变。提交前实际审阅脚本和路径；这是普通本地执行，不是代码沙箱。

读取实际生成的指标、表和说明，打开实际图像或渲染 PDF 检查点、图例、刻度和排版。核对正文关键数字、图表与原始行的一致性；脚本成功退出和来源哈希都不能证明分析正确。如果脚本错误，修正当前派生计算并更新受影响产物并保留前次内容和日志；保留失败日志，不把分析脚本失败自动认定为学生程序失败。生成脚本可以用计算变量填入文字，避免手工复写数字；写完仍需语义检查。

解释重要结果如何回答要求，区分直接观察、计算得到的指标、依赖假设的推断和未确认事项，不强制采用固定章节。说明实质限制，例如缺少重复测量或生成条件；不要根据曲线外观断言复杂度，或把相关变化写成已验证的因果关系。外部或正确性未通过的数据必须带相应限制；可分析失败现象，但不能写成实现已正确。

发现待更新结果时核对具体变更。可确认无影响的变化按结果约定记录实际比较依据；不能确认时保留待复核。补跑或修复已在本次范围内才调用对应行为，并遵守预算与失败恢复规则；仅分析时需要新增实验、重跑学生程序或修改实现，应带具体原因和推荐方案询问范围。只处理受影响的结果组和分析，保留历史，继续独立有效部分。

交付当前指标、图表、解释及可追溯文件，准确说明失败、待更新和未确认项。沿用或建立 Git，按有意义进展提交本次成果，保留用户已有修改和暂存内容；可选辅助接口不是自动提交的前提。下一步由用户目标决定，不强制报告或验收阶段。
