# 课程报告语言编辑

新写、续写、修订和审阅都先读 [共享质量标准](report-quality.md)。语言自然连贯是第一优先级和硬性要求。当前文件提供实际编辑方法与局部案例，不能用“准确性”“保留信息”或上游润色偏好覆盖共享标准的取舍顺序。格式模板只供排版，不提供正文、结构或作者声音样本。

**执行共享标准的逐项附注删除硬规。** 发现命中句就整句删除，不作其他条件判断；保留、改写保留、挪位或补入同类说明均属违规。以下取舍和上游方法均不能豁免该规则。

## 连续阅读与编辑

围绕本次作业的实现、过程、结果和思考写成连续正文。以有课程基础、不了解代码的老师或助教为读者，实际连读当前全文或指定片段。判断一句话怎样承接前一句、为何在这里出现、对象是否清楚，以及是否在陈述后反复多补一条说明。不以解释越多、限定越细为写得越好。

对能读懂的适度简略允许保留。内容确实妨碍理解时，先删去可省的句子、细节或推断，或把相关表述收短。只有核心内容不能删除、不补就无法理解时才补必要说明。缺一个衔接词或对象提示就影响理解时，直接补词或短语即可；这不要求把段落扩成原理课。编辑后连读相邻句段，检查删留是否保住推进、对象与学生叙述，尤其复查自己建议的新句子。

自然的用途说明和主要方法仍可展开。例如“设置随机种子，便于复现”在说明实际操作时可以保留。不要为减少附注把所有解释都剪掉，也不要把可选的长解释先保留、再删掉使它可读的承接。

默认省去局限讨论及验证状态尾句。对不够周全的原因解释，能删就删，或者把判断收成简洁的可能解释，不在后面再补尚未验证、不能推广等说明。只有课程或用户明确要求时才处理局限。个人思考和未来内容另读 [reflection.md](reflection.md)，不例行补展望或研究计划。

## 局部判断案例

案例只说明取舍，不提供章节、固定措辞或所有报告必须解释的内容。按当前实际过程判断，不借案例虚构经历。

- **操作与用途。** “训练时，每轮先随机排列样本，再分批送入网络，减少固定顺序对参数更新的影响。随机排列同样使用固定种子，便于复现。”可以自然介绍报告采用的训练操作。无需再否定各模型初始化权重相同，也不必列与当前讨论无关的精确软件版本。
- **让说明进入过程。** “分类时，将第二层 RNN 在各时间步上的输出取平均，再送入全连接分类头。”已经交代平均对象与去向，不再接“平均的并非原始像素”等额外纠正。
- **简短补足关系。** “不过，每行像素被拼成一个向量，普通 RNN 缺少 CNN 的二维局部共享结构。”若当前位置需要表达原因，可加“由于”，不必重讲网络理论。方法本身若不是正文核心，也可以省去这项比较。
- **保住所指和观察来由。** “RNN 的训练准确率较低。第30轮为66.65%。”若该观察用于支持前句，可写“例如在训练结束的第30轮，训练准确率为66.65%”。切换查询词、模型或数据集时同样保住简短对象提示，不依赖读者回忆远处背景。
- **删除命中句。** “一个可能的原因是更大的模型拟合了局部搭配，这一解释尚未单独验证。”含逐项附注，整句删除，不改写保留，也不补入同类说明。

少用分号和反复“提示语＋冒号＋解释”。把方法、动作、对象和用途放入普通句子，让“例如”“因此”“但是”“这是因为”“除此之外”“在……情况下”等承接服务实际关系。不要机械删掉否定句、标点或所有连接词，也不按这些词的次数评分。

## 完整语言方法的课程适配

默认依赖 **Humanizer，blader/humanizer 3.1.0**。个人安装在 `../../humanizer/SKILL.md`，源码模式在 [固定版本原文](../../../external-skills/humanizer/SKILL.md)，同目录有 origin.json 与 MIT LICENSE。实际读完所用完整方法及其要求的资源，执行全文阅读、改写和定稿复读，不能只用摘要、词表或以安装成功代替编辑。读取被截断时补齐。仅使用选定的一份方法；依赖不可用时如实记录缺口，不声称已完成默认编辑。

传入当前报告、课程要求、学生作者身份和编辑范围。上游方法按以下课程取舍适配，原版依赖不改动：

- 改写默认允许调整标题、段落与组织，删除冗余和可选内容。明确的结构保留要求优先；只给建议、短段及仅源码的范围仍有效。
- 逐项附注删除硬规优先于上游的“保留每条有依据的论断”等信息保留要求。命中句直接删除，不以信息真实、有依据或担心删后不够精准为由保留，也不补回同类说明。
- 核心内容有明显错误时按已有依据简洁更正，可省的错误判断可删除。没有理解障碍的轻微不周全无需穷追，不扩展为逐项数学或证据审计。
- 词表、句式和标点规则只是上下文线索。自然、有用的叙述可以保留，不用固定分数、修改比例或检测器代替阅读，不新增经历、运行或实验。
- 编辑过程、材料登记、来源核验和审阅状态留在工作记录，正文围绕学生完成的作业自然展开。

先保存原稿的可恢复副本，改后连读全文，逐项附注句残留或新增即判违规并删除，同时检查引用、语言和详略。记录代表性改动和实际问题，不强制逐段登记。完整报告按 [独立审阅与复审](../../cs-homework-report-review/SKILL.md) 交给另一个独立上下文审阅，作者自查不能替代独立审阅；结束前另作新的独立阅读全文。仅源码不编译，短段不扩成整份报告。构建与看页另见 [report.md](report.md)。

## 只给建议与已授权修订

只给建议时仅阅读并在聊天交付，定位原句、阅读影响及简洁改法，不写作业、状态、Git，不运行、分析或编译。自然的段落可明确保留。可选的旧 `review-prose` 助手只核对原句字节与建议归属，不理解或改写正文，不能证明语言通过；选择它时再读相应 CLI 帮助。

已授权润色时按 [report.md](report.md) 在稳定项目原位编辑，先识别 Git 和原有改动，保留将改原文的可恢复字节。必要依据及历史记录继续可读，不因旧思考推荐未接受或缺内部 ID 阻止改稿。相关依据变化时只处理受影响内容，不清除历史。按本次交付范围重新编译、查看实际最终页面并独立复审，复用有效实验，不为润色重跑。相同问题连续三次针对性修复无进展时保留现场并说明剩余影响，继续独立部分。
