# 按当前目标验收

先读 [当前范围、工具与跨聊天交接](../cs-homework/references/continuity.md)，再读取本次请求、材料、普通笔记和实际文件。明确要验收的交付物与限制：只检查代码无需报告，只要 LaTeX 源码无需 PDF。旧计划、状态、失败包与下一步只提供背景，不授予新权限。无需统一状态、内部 ID、结果导入或语义审阅 API。

**先复用证据，再按缺口补检。** 核对实际源码、输入、命令、输出和产物；记录中的完成标记、Git HEAD、成功退出或哈希匹配都不能代替当前要求与内容检查。普通“验收，不修实现”允许为缺项、变化或具体疑点追加必要定向检查：读 [cs-homework-run](../cs-homework-run/SKILL.md)，使用普通工具或可选执行助手，保存真实命令、独立预期、原始输出、实际依赖字节与预算事实，说明对应证据缺口。无需为当前请求已包含的必要补检再次确认；保持实现和报告原稿，只检查必要部分，不增加额外实验或参数扫描。

**显式只读、不执行或仅查已有证据时仅阅读并在聊天交付。** 不运行作业程序、分析脚本或编译，不生成图表、写验收/交接或接受记录、更新状态、建立 Git 或提交。缺证据项保持未验证。需要严格只读的 Git 观察时可用 `git --no-optional-locks`，避免索引 stat 缓存写入；这不是必须运行的检查。当前限制始终优先于历史权限。

按当前目标列出全部相关要求，每项保留材料定位、对应交付位置和实际依据。实际核对指定语言、算法、接口、复杂度、依赖/调库限制，再检查教师样例、独立判定、真实输出、边界和覆盖范围。可自行获取的代码、工具和依赖事实直接调查；冲突或实质缺口才提出具体问题并给推荐方案。

已有结果按 [结果与来源](../cs-homework/references/results.md) 核对实际源码、输入、参数、环境及精确版本；分析按 [分析交接](../cs-homework/references/analysis.md) 核对计算、单位、图、表和结论。外部数据保留提供者、已知生成条件与未独立核验的限制，不写成新执行。影响结果的变化只标记相关组待更新并保留历史；无关有效部分继续使用。明确只读时不补跑或保存无影响复核。旧记录中的全局待审状态不能直接当作当前任务失败。

**报告验收**先按 [共享报告质量标准](../cs-homework/references/report-quality.md) 的语言硬性要求通读当前范围，不能以事实或编译通过抵消附注、衔接、对象提示和学生口吻问题。逐项附注句发现即判违规并要求整句删除，不考虑其他任何条件；保留、改写保留、挪位或补入同类说明均属违规，有残留就不能通过，其他编辑取舍不能豁免。实际读 [课程语言方法](../cs-homework/references/report-prose.md)，其他疑点按删减优先处理，只有核心内容不能删除且不补便无法理解时才补说明，默认不追加局限。再核对课程回应、核心内容的明显矛盾，以及总篇幅和各部分分配是否适合当前任务情境，不把报告验收扩大为精密学术审计。当前有效的 [独立审阅](../cs-homework-report-review/SKILL.md) 具体意见可以复用，旧语言通过标签不能代替当前阅读。构建与个人思考按需读 [report.md](../cs-homework/references/report.md) 和 [reflection.md](../cs-homework/references/reflection.md)。此报告分支不改变前述代码、运行和数据验收要求。

完整报告经实质修订后，结束依据须包含 [独立审阅的最终全文判断](../cs-homework-report-review/SKILL.md)，实际对应当前稿及其范围，不能以旧问题全部勾销或作者自查代替新的独立阅读。有剩余问题时，已授权修订就沿该入口继续；仅验收时报告问题及影响。局部任务只核对当前交付及受影响上下文，不强制整篇报告重审。

PDF 目标须有当前源码与素材的实际 LaTeX 编译、引用诊断和全部最终页面审阅依据。已有有效证据可复用，实际页面可以直接打开；缺页或未查看的版面保持未验证。普通验收确需补编译/渲染时，在独立检查目录或新输出位置处理，保留原源码、PDF 与记录，保存真实命令、诊断和页面。失败时报告原因，未授权修改报告时不改源文件。显式只读或不编译时不补编译。源码目标核对可编辑项目完整性，如实说明未编译。

个人思考按实际采用段落、代码、结果与原理判断是否有依据。保留原回复、推荐、真实接受与历史链接；pending、mixed、未登记或旧 require_accepted 标记本身不降级当前有效报告。相关依据变化仍须比较具体论断并核对受影响内容、审阅及构建证据；未采用问题与无关历史变化不使当前报告失败。缺少人类回复不要求采访，也不伪造接受或经历。

在聊天中逐项说明通过、失败、待更新、未验证，列具体依据、缺项、受影响交付物/结果组和下一步；可用简表。具体证据缺口和历史来源状态分别说明。部分成功只宣称相应部分完成，继续不依赖阻塞的核对。

需要机械核对已声明文件或旧登记身份时，才读 [可选验收事实助手](../cs-homework/references/acceptance.md)。`check` 始终只读，不补检、不证明语义正确；它的 JSON/ID 协议仅属于可选助手。`review-report` 会写记录，属于明确选择的旧可写报告路径，不能代替只读验收；普通阅读与反馈不需要调用审阅命令。

**当前组合任务已授权修复时**，失败才衔接 [cs-homework-code](../cs-homework-code/SKILL.md)、[cs-homework-report](../cs-homework-report/SKILL.md) 或 [cs-homework-analyze](../cs-homework-analyze/SKILL.md) 连续处理。交接包含对应要求与定位、原输入/独立预期、实际输出/日志、源码与结果版本、具体诊断或剩余假设、影响范围和当前权限。先区分实现、环境/配置、输入与验证依据原因，再针对原因修复；正确教师用例和独立预期持续有效。

必要实现或报告修改、额外实验尚未授权时，提出带诊断、最小推荐处理和影响的具体范围问题，保留现场并继续独立部分。已授权修复无需重复询问；同一问题连续三次有针对性修复无进展暂停相关部分，长实验遵守试跑估时与当前预算，不换问题 ID 清零。修复后只核对原失败和必要相关项，保留历史、原用户修改与暂存区，并按共享约定保存本次自有成果。显式只读任务的诊断与问题只在聊天交付。
