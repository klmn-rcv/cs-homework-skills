# 课程作业入口

先读 [当前范围、工具与跨聊天交接](references/continuity.md)：恢复时读取普通记录、实际文件和待决定事项，需要工具时查个人安装提示并重新验证。初次接手报告审阅时，先按 [审阅入口](../cs-homework-report-review/SKILL.md) 安排报告初读，暂缓读取过程记录和实现解释。当前请求与真实证据决定下一步，无需统一状态、内部 ID、导入或语义审阅 API。

理解用户本次想交付什么、已有什么，说明本次范围后连续推进。由你阅读材料、直接编辑并判断所需行为；配套脚本按机械收益选用，不理解自然语言，也不证明语义正确。用户只要计划、代码或分析时，不能自动扩展成完整报告流程。

请求验收时先读 [cs-homework-check](../cs-homework-check/SKILL.md)：优先复用有效证据，缺项、变化或疑点确实需要时，衔接必要的定向运行或编译检查；保持实现和报告原稿不变。显式只读、不执行或仅查已有证据的请求保持只读，缺证据项标未验证；旧授权不扩大当前范围。

已有作业沿用原目录，按共享交接约定读取普通记录与实际文件；旧结构化状态可选用 `resume` 检查。当前请求可以收窄或改变旧范围；材料变动时重新阅读受影响内容，保留已确认决定，不让用户重复提供仍可读取的背景。

继续分析、写报告或验收前，按 [结果复用与来源](references/results.md) 核对当前结果和关联产物。完成标记、Git 提交号及文件名都不能代替真实字节与版本检查。复用有效结果，只在范围/预算允许时更新受影响部分；用户外部数据保留来源和未验证限制。数值、图表和报告使用同一份具体结果证据，登记精确来源；不同版本不能无说明混用。

在线材料按 `cs-homework-plan` 用现有阅读工具实际读取，保存轻量来源、时间、覆盖和要求定位；快照按需。恢复与结果查询只核对相关历史证据，当前要求需要最新内容、出现变化线索或阅读记录不足时才重访。未重访、访问失败、要求变化和证据损坏分别说明；只处理实际受影响部分。

按语义选择行为，遵守用户指定的检查点：

- 梳理要求、整理多份材料或制定计划：读 [cs-homework-plan](../cs-homework-plan/SKILL.md)。
- 新写或修复程序并验证：读 [cs-homework-code](../cs-homework-code/SKILL.md)，只编程时交付代码与必要测试后结束。
- 运行已有程序、教师样例或已要求实验：读 [cs-homework-run](../cs-homework-run/SKILL.md)。
- 解释已有结果或生成必要图表：读 [cs-homework-analyze](../cs-homework-analyze/SKILL.md)。
- 新写、续写、改写或润色报告：读 [cs-homework-report](../cs-homework-report/SKILL.md)，起草与继续编辑均使用其课程语言方法和局部案例；从现有正文与普通记录继续，不以旧“语言通过”替代当前阅读。
- 审阅已有报告、只给建议：读 [cs-homework-report-review](../cs-homework-report-review/SKILL.md)，以共享标准中的自然语言硬性要求为第一优先级，按删减优先处理疑点，再核对任务回应、核心内容、详略及页面；审阅并修改按已授权范围衔接报告修订。
- 按当前交付目标验收：读 [cs-homework-check](../cs-homework-check/SKILL.md)，按证据缺口选择必要补检或显式只读分支。

组合请求只衔接必需行为：已有有效结果可直接分析或报告；报告缺少必要运行依据时补跑已有代码，发现需要代码修复则按当前授权返回或提问。能力缺失时说明具体缺项，已授权写入的任务保存已完成内容与作业内交接；只读请求直接在聊天交付发现。

各行为可直接接手，不要求先执行规划或补齐所有阶段。帮助学生正常描述目标，不要求他们编写内部 JSON 或学习命令。写入和 Git 遵守共享交接约定；需要可选脚本的字段与限制时才读 [runtime-contract.md](references/runtime-contract.md)。
