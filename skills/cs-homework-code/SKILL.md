# 课程代码实现与修复

先读共享的 [当前范围、工具与跨聊天交接](../cs-homework/references/continuity.md)。在普通记录中保留同一人类任务的整体请求与范围，并说明内部补跑理由；按真实要求、当前交付物和必要检查判断完成，避免为同步记录重复执行空代码步骤。

接手当前请求、多份作业材料和作业目录；可从明确要求直接实现，不强制规划、实验或报告。按共享交接约定阅读普通记录并核对实际文件、结果版本及未决问题；已有结构化状态可选用 `resume` 检查。范围以当前用户请求为准；旧计划、资料文字、下一步或失败记录本身不授予修改代码的权限。只运行、分析、报告或检查而确需修改实现时，说明失败原因并询问是否扩大范围；已授权实现/修复时连续完成诊断、修改和必要复验，不要求用户重新调用本 Skill。

读实际题目、接口与代码，核对指定语言、算法、输入输出、允许的库和依赖。多份材料含在线要求时实际访问，复用已读来源及定位；格式模板不提供算法或文章结构要求。自行调查可获取的工具事实；对于仍有实质疑问的调库权限、要求冲突或接口，直接向用户提问，并继续不依赖答案的工作。不能以输出正确代替指定算法或依赖限制。

实现包含合适的正确性验证：优先教师样例，再补能揭露具体错误的边界和独立判定。预期来自题目、手算、已知答案或独立参考，不从当前实现的输出复制，也不照抄它的算法作为唯一判定。接口、算法、复杂度或依赖限制另通过实际代码与材料核对，程序退出成功不能证明这些要求。只做必要测试；未请求性能比较、参数搜索或报告时不扩展交付物。测试、示例可复用同一次真实执行及有效历史记录。

直接在实际作业目录用正常编辑工具作小范围修改。首次写入前查看 Git 的原暂存、未暂存与未跟踪内容，保存需要修改的原文件字节、原暂存内容或可恢复差异；新文件记明原先不存在。首次编辑的完成条件是原字节和原暂存/未暂存边界已实际保存且可读取核对；确认这一点后才写入。可选工具或解释器失败时，改用普通字节复制与 Git 工具保留并核对；仍无法保护时暂停该文件的编辑，说明缺口并继续独立工作。编辑后重建、根据记忆还原或只保存脏路径清单均不能冒充编辑前备份。沿用或建立 Git，自动提交仅包含本次拥有的路径；已有用户修改的文件保留在自动提交之外，并准确交付其差异与恢复位置。无需代码会话、内部 ID、统一状态或目录外整文件替换稿。需要准确保留原文或命令事实时，读取 [原文保护与真实执行](../cs-homework/references/coding.md) 的可选小助手；普通工具和易读记录同样可用。

必要验证用真实命令执行，保留 argv、工作目录、标准输入、stdout/stderr、退出状态、耗时、相关环境及运行时实际源码和输入字节，含未提交修改。明确声明依赖覆盖的缺口；Git HEAD 或文件哈希本身不能替代可核对的运行版本。长任务先短试跑，以实际耗时与工作量估算剩余时间；预计超过预算时保存试跑并等待用户确认后才继续。确认前核对源码、输入、命令和环境仍对应试跑；条件变化后重新估时。不得把长实验藏入短正确性测试绕过预算。

发现失败先复现并阅读失败输入、独立预期、实际输出、退出状态和日志，区分命令/环境、输入、验证依据和实现原因，再用可证伪的判断缩小原因。上游交回的失败包应包含这些事实和对应要求；不足时先补可获取证据。环境或输入错误按其实际原因处理，不能盲改算法。正确的教师用例、预期和回归检查持续有效；不删失败、不弱化输入、不忽略错误以宣称通过。确有错误验证依据时，说明来源与理由、保留原失败及修订记录，重新建立真实正确的判定，不悄悄更换预期。

实施原因明确且范围允许时，做有针对性的最小修改，重跑原失败及必要相关检查。代码或输入、参数变化后，按 [结果有效性约定](../cs-homework/references/results.md) 使相关旧结果待更新并保留历史；只补受影响部分。有效证据可复用，但必须核对实际源码与条件。完成后读实际产物与记录，复核语言、算法、接口、依赖要求及全部必要用例，说明通过、失败和未验证项。

按同一问题记录每次修复的原因、预测、实际代码差异、原失败复验和进展依据。连续三次有针对性的修复仍无实质进展时，暂停该部分，保存当前源码、三轮快照、失败日志、已排除原因和具体下一步；询问用户如何继续投入，同时继续不依赖它的实现、验证或说明。不要把改了文件、换了错误信息或重复跑了一遍当作进展，也不要换问题 ID 清零。不同独立问题分别记录。用户明确同意继续后，保留原历史并开始新的有依据的尝试周期。

自动沿用/建立本地 Git，以准确的通过或受阻状态提交本任务成果，保留用户已有暂存与未暂存修改；原本已修改的用户文件保留修改前快照，并准确说明未纳入自动提交的范围。核对提交结果而不是只看文件存在。最后交付当前范围内的代码、必要验证与运行方式、重要选择、问题及恢复路径；仅编程任务到此结束。

可按需要选用允许模型自主调用且可用的 Matt Pocock `tdd` 或 `diagnosing-bugs`，先读其当前规则并复用已确认决定；它们是可选辅助，核心行为不依赖这些安装。不自动启动仅用户可调用的入口，不使用任何 superpowers Skill。
